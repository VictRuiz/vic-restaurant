# 🍽️ Vic Restaurant

Sitio web moderno para Vic Restaurant - Donde la Tradición se Encuentra con la Vanguardia

![Vic Restaurant](https://img.shields.io/badge/Status-Live-success)
![Webpack](https://img.shields.io/badge/Webpack-5.89-blue)
![License](https://img.shields.io/badge/License-ISC-green)

## 🌟 Características

- ✨ Diseño moderno con animaciones y efectos interactivos
- 🎨 Logo SVG personalizado
- 📱 Diseño responsive (móvil, tablet, desktop)
- 🖼️ Galería de menú con imágenes de alta calidad
- 🎯 Navegación SPA (Single Page Application)
- ⚡ Optimizado con Webpack
- 🌐 Deploy automático en GitHub Pages


### Página de Inicio
Experiencia hero con fondo parallax y animaciones suaves.

### Menú Degustación
Tarjetas interactivas con imágenes de platos gourmet.

### Contacto
Información de contacto con diseño glassmorphism.

## 🛠️ Tecnologías

- **HTML5** - Estructura semántica
- **CSS3** - Estilos modernos con animaciones
- **JavaScript ES6+** - Lógica de la aplicación
- **Webpack 5** - Bundler y optimización
- **Babel** - Transpilación para compatibilidad
- **GitHub Pages** - Hosting gratuito

## 🏗️ Build para Producción

```bash
# Crear build optimizado
npm run build

# Los archivos estarán en la carpeta /dist
```

## 🌐 Deploy

```bash
# Deploy a GitHub Pages
npm run deploy
```

## 📁 Estructura del Proyecto

```
vic-restaurant/
│
├── src/
│   ├── index.html          # HTML principal
│   ├── index.js            # Entry point de JavaScript
│   ├── style.css           # Estilos globales
│   └── modules/
│       ├── home.js         # Módulo página inicio
│       ├── menu.js         # Módulo página menú
│       └── contact.js      # Módulo página contacto
│
├── dist/                   # Build de producción (generado)
├── webpack.config.js       # Configuración de Webpack
├── package.json           # Dependencias y scripts
└── README.md              # Este archivo
```

## 👨‍💻 Desarrollo

### Scripts disponibles:

- `npm start` - Inicia servidor de desarrollo
- `npm run build` - Crea build de producción
- `npm run deploy` - Deploy a GitHub Pages
- `npm run watch` - Observa cambios en tiempo real
